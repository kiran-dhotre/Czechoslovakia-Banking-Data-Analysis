# Czechoslovakia-Banking-Data-Analysis
SQL-based banking data cleaning, financial analysis, and business insights using MySQL and Power BI.

## Project Overview

This project analyzes banking financial data using MySQL and Power BI, focusing on data cleaning, transaction analysis, and business insights.

## Tools Used
- MySQL
- Power BI

## Project Files
- `bank1_data_cleaning.sql` — Data cleaning queries
- `bank_AD_HOCK_analysis.sql` — Ad-hoc analysis queries
- Power BI dashboard (`.pbix`)
- Project report and presentation
- Data cleaning documentation
